# 力扣题单

这个目录用来按题型整理 LeetCode 复习内容，方便后续按专题回顾，而不是只按题号零散存放。

## 目录说明

- 每个子目录对应一个专题，例如：滑动窗口、并查集
- 专题目录下优先放 `review.md`，用于沉淀该题型的核心套路、易错点和复习入口
- 具体题目的题解仍然可以保留在原题目录中，题单目录侧重“分类导航”和“复习索引”

## 题型分类

- [滑动窗口](./滑动窗口/review.md)
- [并查集](./并查集/review.md)
- [堆](./堆/readme.md)

## 复习建议

- 先看专题 `review.md`，快速回忆这个题型解决什么问题
- 再看该专题下已经整理过的代表题
- 复习时重点关注：识别特征、核心模板、边界处理、常见误区

## 刷题方向

短期目标优先放在“能快速识别题型、能稳定复现代码”的专题上，不优先硬啃多个技巧组合在一起的高级题。

推荐顺序：

1. 哈希、数组、双指针
   - 目标：看到题能判断是用哈希表记录状态，还是排序后双指针收缩。
   - 代表方向：两数之和、三数之和、最长无重复子串。
2. 滑动窗口
   - 目标：熟悉定长窗口、变长窗口、计数窗口。
   - 重点关注：窗口何时扩张、何时收缩、答案何时更新。
3. 栈和单调栈
   - 目标：能识别“下一个更大/更小元素”“左侧/右侧第一个满足条件的位置”。
   - 代表方向：每日温度、下一个更大元素、柱状图最大矩形。
4. 堆基础和 Top K
   - 目标：掌握用堆维护候选、动态取最大/最小。
   - 代表方向：第 K 大元素、前 K 高频元素、合并 K 个有序链表、数据流中位数。
5. 二分答案
   - 目标：会把问题转成 `can(mid)` 判断。
   - 重点关注：边界、单调性、返回值含义。
6. 基础动态规划
   - 目标：先练状态定义和转移，不追求偏题怪题。
   - 代表方向：爬楼梯、打家劫舍、最长递增子序列、最长公共子序列。
7. 高级组合题
   - 目标：复盘思路和模板，不作为短期主刷方向。
   - 代表方向：`ST 表 + 堆`、`堆 + 多路归并`、`单调性 + 数据结构`。

例如 `3691. 最大子数组总值 II` 属于高级组合题。当前阶段只需要记录它的三个关键点：

- 固定左端点后，右端点变化形成单调不降序列。
- 堆里维护 `[value, l, r]`，每次弹出当前最大候选。
- ST 表负责快速查询任意 `[l,r]` 的最大值和最小值。

这类题可以理解思路、整理题解、后续二刷，不需要短时间强行背代码。
